"이제 이 프로젝트에 '사고 연결(Thought Bridge) 및 역지문' 기능을 추가해 주세요."
1. 입력 인터페이스: 화면 하단이나 측면에 '오늘의 생각 입력'창을 만들어 주세요.
2. 가중치 기반 검색 로직 (Core Logic): 사용자가 새로운 생각(C)을 입력하면, 기존의 모든 노드와 비교하여 **'연결 점수(Bridge Score)'**를 계산합니다.
점수 계산식: Score = (Semantic Similarity * 0.7) + (Time Recency * 0.3) (즉, 시간적으로 조금 멀더라도 주제가 매우 비슷하면 가중치를 더 높게 둡니다.)
3. 시각적 피드백: 가장 점수가 높은 노드(과거의 생각 A)를 3차원 공간에서 강렬하게 반짝이게(Highlight) 하고, 카메라가 그 노드를 부드럽게 줌인(Zoom-in)하게 해주세요. 현재의 입력값(C)과 선택된 과거 노드(A) 사이에 **굵은 빛의 선(Link)**을 연결해 주세요.
4. AI 역지문 생성 (Reverse Question): 선택된 과거 노드(A)의 내용과 현재 입력(C)의 내용을 바탕으로 LLM이 질문을 던지게 해주세요.
질문 스타일: "당신은 [과거 시점]에 [주제 A]에 대해 이러이러한 생각을 했었네요. 그런데 지금 [주제 C]에 대해선 이렇게 말씀하시네요? 그 사이에 어떤 심경의 변화가 있었나요?" 와 같은 통찰력 있는 질문이어야 합니다.
5. UI 요소: 이 질문은 화면 우측의 'Reflection Panel'에 타이핑 효과와 함께 나타나게 해주세요. 

"노드 클릭 시 상세 정보를 보여주는 '생각 인스펙터(Thought Inspector)' 기능을 추가해 주세요."

1. 클릭 이벤트 처리 (Event Handling):

react-force-graph-3d의 onNodeClick 이벤트를 사용하여, 사용자가 특정 구(Sphere)를 클릭하면 해당 노드가 화면 중앙으로 부드럽게 포커싱되게 해주세요.

클릭된 노드는 다른 노드들과 구분되도록 더 밝게 빛나거나 테두리(Glow Effect)가 생기게 해주세요.

2. 상세 정보 패널 (Detail UI):

노드를 클릭했을 때 화면 한구석(혹은 노드 옆)에 세련된 **반투명 유리 질감(Glassmorphism)**의 카드 UI를 띄워주세요.

카드에는 다음 정보가 포함되어야 합니다:

일시: timestamp 데이터를 "2026년 3월 25일 오후 8시"와 같은 읽기 쉬운 형식으로 변환하여 표시.

주제: keywords들을 해시태그(#) 형태로 나열.

내용: 해당 시점에 기록했던 text 전문.

수치: 당시의 뉘앙스(긍정/부정)와 생각의 깊이를 시각적인 바(Bar)나 아이콘으로 표시.

3. UI 인터랙션:

카드의 우측 상단에 '닫기(X)' 버튼을 만들어 주세요.

빈 공간(배경)을 클릭하면 선택된 노드가 해제되고 상세 정보 패널이 사라지게 해주세요.
