나는 AI 사용은 익숙하지만, 본격적인 바이브 코딩(AI 주도 개발)은 처음입니다. 내 생각의 흐름을 다차원 벡터 공간에 시각화하고, 이를 탐험하며 나를 이해하는 "3차원 자아 연대기(Memory Chronicle 3D)" 웹 애플리케이션의 프로토타입을 만들고 싶습니다. 다음 지시사항에 따라 프로젝트를 생성하고 코드를 작성해 주세요:
1. 기술 스택 및 환경 설정
Framework: React (+ Vite)
Language: JavaScript
3D Visualizer: Three.js를 직접 다루는 것은 복잡하므로, 이를 추상화한 react-force-graph-3d 라이브러리를 사용해 주세요. (또는 최신 라이브러리 중 더 나은 대안이 있다면 추천해 주되, 구현이 쉬워야 합니다.)
2. 데이터 스키마 (The Vibe Data)애플리케이션 내부에서 사용할 50개의 더미 데이터를 생성해 주세요. 데이터는 다음과 같은 N-차원 정보를 포함해야 합니다:
JSON{
  "id": "unique_id",
  "text": "내가 한 생각이나 일기의 내용 (랜덤 생성)",
  "timestamp": "2020-01-01T12:00:00Z (5년간 균등 분포)",
  "nuance": 0.0, // 뉘앙스 축: -1.0(매우 부정) ~ 1.0(매우 긍정)
  "depth": 3, // 생각의 깊이 축: 1 ~ 5 (정수)
  "keywords": ["주제1", "주제2"], // 유사성 계산을 위한 태그
  // 중요: AI는 이 정보를 바탕으로 내부적으로 3차원 벡터(embedding)를 계산했다고 가정하고,
  // 시각화에 사용할 x, y, z 좌표를 랜덤하게 생성해서 넣어주세요.
  "context": "내용 요약",
  "coords": { "x": 10, "y": -5, "z": 20 }
}
3. UI/UX 및 시각화 요구사항 (핵심)
- 화면: 3차원 공간 전체를 꽉 채우는 화면. 배경은 어둡게(Dark Mode) 해주세요.
- 노드(생각 점): 데이터 하나당 하나의 다채로운 '빛나는 구(Sphere)'로 표현해 주세요.
- 다양한 색상 활용 (뉘앙스 그라데이션): 노드의 색상은 nuance 값에 따라 매우 다채롭고 직관적으로 그라데이션 되어야 합니다.
> 예: 매~우 부정(-1)은 강렬한 빨강 → 중간(0)은 연한 녹색/회색 → 매~우 긍정(1)은 투명한 네온 블루 (이런 식의 다채로운 색 조합을 제안해 줘.)
- 크기 (깊이): depth 값에 따라 노드의 크기가 달라지게 해주세요. (깊을수록 큼)
- 시계열 연결: 데이터들을 timestamp 순으로 얇은 선으로 연결하여 생각의 흐름을 보여주세요.
- 검색 및 유사성: 상단에 검색창을 하나 만들어 줘. 검색어를 입력하면, 그 검색어와 keywords가 가장 유사한 노드들만 밝게 빛나고, 나머지는 흐려지게 해 줘.
4. 상호작용
마우스로 3차원 공간을 회전(Orbit), 확대/축소(Zoom) 할 수 있어야 합니다. 노드 위에 마우스를 올리면(Hover) 해당 생각의 text와 nuance 값이 툴팁으로 뜨게 해주세요.
